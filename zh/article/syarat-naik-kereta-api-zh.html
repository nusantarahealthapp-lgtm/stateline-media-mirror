长途火车乘车最新条件：从证件要求到行李规定

Stateline MEDIA 新闻编辑室•14 十月 2026•1 分钟阅读

想乘坐火车吗？这是2026年的最新规定：身份证件、20公斤行李规则、违禁物品，以及人脸识别登车。

关键事实

  • 乘客必须携带原件身份证件（KTP/KK/护照），且证件上的姓名须与机票信息完全一致。
  • 建议至少在发车时间前60分钟到达车站，以便办理登机手续。
  • 如今在大型车站办理登车手续，大多数已采用人脸识别技术，无需打印纸质车票。
  • 免费行李额为每位乘客最多20公斤，最大尺寸为100立方分米（70厘米 x 48厘米 x 30厘米）。
  • 超重行李费为行政舱每公斤10,000印尼盾至经济舱每公斤2,000印尼盾。
  • 禁止携带的物品包括动物、榴莲、利器以及易爆或易燃物品。

证件必须随身携带

乘坐长途列车的主要条件是携带仍在有效期的身份证原件——身份证（KTP）、家庭卡（KK）或护照——且姓名必须与车票上所登记的完全一致。工作人员将在检票上车时核对信息是否相符。

建议乘客至少在发车前60分钟到达车站，以便有足够的时间排队并进入站台。在大型车站，检票上车流程如今大多采用人脸识别技术：只需在机器上扫描面部即可，无需打印纸质车票。

需要遵守的行李规定

每名乘客可享最多20公斤的免费行李额度，行李尺寸最大为100立方分米（70厘米 x 48厘米 x 30厘米）。超重行李收费从行政舱的每公斤10,000印尼盾到经济舱的每公斤2,000印尼盾不等。

超大件行李若妨碍车厢通道，列车员可以将其请下车。折叠自行车或轮椅则须确保尺寸符合专用行李舱的规定。

禁运物品与特殊乘客

为了安全起见，一些物品禁止带入火车，其中包括动物、榴莲、利器以及易爆或易燃物品。请遵守这些规定，以免旅途受到影响。

6岁以下的乘客必须由符合乘车条件的成年人陪同。如需特殊协助——例如为老年人或残障人士提供轮椅——请提前联系KAI客服，可拨打客服热线121、WhatsApp号码0811-2111-121，或发送电子邮件至cs@kai.id。

登机流程顺利的小贴士

请提前在大车站的人脸识别注册机上注册您的面部信息——等到出发当天,您只需扫描面部即可,无需排队出示身份证(KTP)。如果尚未注册,请准备好实体身份证以及来自 Access by KAI 应用的电子登车凭证(e-boarding pass)。

将手机充满电，并提前离线下载电子车票作为备用。在节假日或周末，请比建议的60分钟更早到达，因为安检排队往往会更长。将呼叫中心号码121存入手机以备旅途中紧急情况使用，并在到达目的地下车前再次检查随身行李。
