Cara Isi Token Listrik PLN via HP: PLN Mobile hingga M-Banking

Redaksi Stateline MEDIA•14 Oktober 2026•3 mnt baca

Isi token listrik prabayar kini bisa dari HP: beli lewat PLN Mobile, m-banking (BRImo, Livin’, m-BCA), minimarket, atau marketplace, lalu masukkan 20 digit kode ke meteran dan tekan Enter.

Daftar Isi

  1. Beli dan Isi Token Listrik Cukup dari HP
  2. Cara Beli Token via PLN Mobile
  3. Cara Beli via M-Banking dan Minimarket
  4. Cara Memasukkan Token ke Meteran

Fakta Utama

  • Token listrik prabayar bisa dibeli lewat aplikasi PLN Mobile: pilih menu “Kelistrikan” → “Token dan Pembayaran” → masukkan ID pelanggan → pilih nominal → bayar → lihat kode 20 digit di “Lihat Transaksi Saya”.
  • Pembelian juga tersedia di m-banking: BRImo (Isi Ulang → PLN → Prabayar), Livin’ by Mandiri (Top Up/Beli → PLN Prabayar), dan m-BCA (m-Commerce → PLN Prabayar) — kode token dikirim lewat notifikasi atau SMS.
  • Di minimarket seperti Alfamart atau Indomaret, cukup tunjukkan nomor ID pelanggan ke kasir, sebutkan nominal, bayar, lalu terima struk berisi 20 digit kode token.
  • Marketplace seperti Tokopedia, Shopee, dan Lazada juga menjual token listrik prabayar.
  • Cara memasukkan token: ketik 20 digit kode pada meteran lalu tekan Enter (tombol panah hijau); bila muncul “BENAR”, jumlah kWh bertambah. Jika salah memasukkan kode 3 kali, meteran bisa terblokir otomatis dan perlu bantuan PLN untuk membuka blokirnya.

Beli dan Isi Token Listrik Cukup dari HP

Pengguna listrik prabayar tidak perlu lagi keluar rumah untuk membeli token. Kode token 20 digit kini bisa dibeli lewat HP — mulai dari aplikasi resmi PLN Mobile, mobile banking, hingga marketplace — lalu dimasukkan sendiri ke meteran.

Nominal token bervariasi, umumnya mulai dari Rp20 ribu ke atas. Setelah pembayaran berhasil, Anda menerima 20 digit kode yang siap diisikan ke kWh meter di rumah.

Cara Beli Token via PLN Mobile

Buka aplikasi PLN Mobile yang sudah terpasang, lalu pilih menu “Kelistrikan”. Masukkan ID pelanggan atau nomor meter; jika belum tersimpan, gunakan fitur “Token dan Pembayaran”.

Pilih nomor ID pelanggan, klik “Beli Token”, tentukan nominal yang diinginkan, lalu pilih metode pembayaran dan selesaikan transaksi. Setelah berhasil, klik “Lihat Transaksi Saya” untuk melihat nomor token 20 digit yang bisa dimasukkan ke meteran.

Cara Beli via M-Banking dan Minimarket

Lewat BRImo: buka aplikasi, pilih “Isi Ulang” → “PLN” → jenis transaksi “PLN Prabayar” → masukkan ID pelanggan → pilih nominal → konfirmasi dengan PIN. Kode voucher dikirim lewat SMS. Lewat Livin’ by Mandiri: menu “Beli” atau “Top Up” → “PLN Prabayar” → masukkan ID pelanggan → pilih nominal → konfirmasi dengan MPIN. Lewat m-BCA: “m-Commerce” → “PLN Prabayar” → masukkan nomor meter/ID pelanggan → pilih nominal.

Bagi yang tidak memakai m-banking, kunjungi minimarket terdekat seperti Alfamart atau Indomaret. Tunjukkan nomor ID pelanggan ke kasir, sebutkan jumlah pulsa yang dibeli, lakukan pembayaran, dan kasir akan memberikan struk berisi 20 digit kode. Marketplace seperti Tokopedia dan Shopee juga menyediakan pembelian token listrik.

Cara Memasukkan Token ke Meteran

Pergi ke kWh meter di rumah, ketik 20 digit nomor token dengan teliti, lalu tekan tombol “Enter” atau tombol panah hijau. Jika kode benar, meteran berbunyi dan menampilkan label “BENAR”, dan jumlah kWh bertambah sesuai nominal yang dibeli.

Perhatian: jangan sampai salah memasukkan kode. Jika salah 3 kali, meteran akan terblokir otomatis — Anda harus menghubungi PLN untuk membuka blokirnya. Jika muncul tulisan “SALAH” atau “REJECT”, periksa kembali digitnya sebelum menekan Enter.
