Gunung Arjuno Terbakar, Api Terlihat dari Tol Malang-Pasuruan

Redaksi Stateline MEDIA•16 Oktober 2026•3 minit bacaan

Kebakaran hutan dan tanah melanda kawasan puncak dan lereng Gunung Arjuno di sempadan Kota Batu, Kabupaten Malang, dan Kabupaten Pasuruan, Jumaat (16/10/2026) malam. Marak api kelihatan jelas dari Pandaan, Pasuruan, hingga ruas tol arah Malang. BPBD Jawa Timur mengesahkan pasukan gabungan bergerak ke lokasi, dan seluruh laluan pendakian Arjuno-Welirang ditutup sepenuhnya buat sementara waktu.

Fakta Utama

  • Kebakaran hutan berlaku di kawasan puncak Gunung Arjuno, sempadan Kota Batu, Kabupaten Malang, dan Kabupaten Pasuruan, Jawa Timur, Jumaat (16/10/2026) malam.
  • Titik api pertama muncul sejak Khamis (15/10/2026) petang dan terus menyala hingga Jumaat malam.
  • Api jelas kelihatan dari Pandaan, Kota Pasuruan, Tretes (Prigen), dan ruas tol arah Malang KM 54-60.
  • Api merebak ke Gunung Kukusan, Gunung Ringgit dan Bukit Nogo; dua titik api baharu muncul di Puncak Ringgit.
  • Ketua Pelaksana BPBD Jawa Timur Gatot Subroto mengesahkan kebakaran dan penggerakan pasukan darat dari Jatim, Mojokerto, Pasuruan, serta Tahura.
  • Semua laluan pendakian Gunung Arjuno dan Welirang ditutup sepenuhnya buat sementara waktu demi keselamatan.

Api Marak Terlihat dari Pasuruan hingga Tol Malang

Hutan dan tanah terbakar (karhutla) melanda kawasan puncak serta lereng Gunung Arjuno yang masuk wilayah Taman Hutan Raya (Tahura) Raden Soerjo, Jumat (16/10/2026) malam. Kobaran api yang menyala serta kepulan asap tebal terpantau jelas hingga ke wilayah Kota Pasuruan.

Api mula kelihatan membesar pada Jumaat tengah hari dan semakin jelas pada waktu malam dari kawasan Kota Pasuruan, Pandaan, Tretes (Prigen), ruas jalan tol arah Malang (KM 54-60), hingga kawasan sekitarnya. Daripada beberapa rakaman yang tersebar di media sosial, api kelihatan menyala merah membentang di lereng gunung.

Api marak dikesan bermula dari kawasan Perengkilu dan merebak ke beberapa titik, antaranya kawasan Arjuno, Lembah Kijang, Pondok Lembu, serta beberapa titik di Kecamatan Prigen seperti Kelurahan Ledug, Desa Dayurejo, dan Desa Jatiarjo.

Api merebak ke Gunung Ringgit dan Bukit Nogo

Pada mulanya titik api sudah muncul sejak Khamis (15/10/2026) petang dan masih menyala sehingga kini. Kebakaran di kawasan Puncak Ringgit di lereng Gunung Arjuno, Kecamatan Prigen, Kabupaten Pasuruan, dilaporkan terus merebak sehingga malam.

Fire also spread to several mountain hills around Mount Kukusan, Mount Arjuno, Mount Ringgit and Bukit Nogo. Two new fire points were reported to have appeared simultaneously at Puncak Ringgit, forming a blazing red line along the slopes covered in dry vegetation.

Penyebaran api berlaku disebabkan angin kencang dan tumbuh-tumbuhan yang kering. Kontur cerun yang curam serta jarak penglihatan yang terhad pada waktu malam menjadi cabaran tersendiri dalam usaha pengendalian di lokasi.

BPBD Jatim dan Tim Gabungan Dikerahkan

Ketua Pelaksana BPBD Jawa Timur, Gatot Subroto, mengesahkan kebakaran tersebut dan memastikan pasukan darat bergerak ke lokasi. "Benar ada kebakaran hutan di puncak Arjuno dan pasukan darat daripada Jatim, Mojokerto dan Pasuruan serta pasukan Tahura bergerak ke lokasi," katanya.

Pasukan pemadam darat bersama yang dikerahkan terdiri daripada BPBD Provinsi Jawa Timur, BPBD Kabupaten/Kota berkaitan, TNI (Kodim 0819 Pasuruan), Polri, petugas UPT Tahura Raden Soerjo, serta unsur sukarelawan. Menurut laporan awal, seramai 11 anggota dikerahkan untuk memadamkan api, terdiri daripada empat petugas Tahura dan tujuh sukarelawan.

Measures are focused on limiting the spread of fire to prevent it from reaching the wider conservation forest area, including creating firebreaks so that the fire does not spread further.

Seluruh laluan pendakian ditutup sepenuhnya

Sebagai langkah berjaga-jaga dan keselamatan, seluruh laluan pendakian Gunung Arjuno dan Welirang ditutup semula sepenuhnya buat sementara waktu. Laluan pendakian melalui Bukit Cendono juga ditutup demi keselamatan.

Laluan pendakian di sekitar lokasi berada di bawah pengawasan ketat demi menjaga keselamatan pendaki, petugas dan masyarakat. Kebakaran di kawasan pergunungan berpotensi merebak dengan cepat apabila disokong angin kencang dan bahan bakar semula jadi yang mengering.

Setakat berita ini disusun, belum ada maklumat yang disahkan mengenai keluasan kawasan yang terbakar mahupun punca sebenar kebakaran. Carian "gunung arjuno" melonjak lebih 800 peratus di Google Trends Indonesia pada Jumaat malam, menandakan peristiwa ini menjadi perhatian awam nasional.
